# 抖音创作者工作流

先确定本次交付的是本地预览、平台草稿、立即发布还是定时发布。打开项目排期表和发布记录，按目标账号核对固定作品 ID、标题和媒体版本。发布前也查旧标题和旧版本。排期、草稿和已发布分别记录。

## 创作者中心

1. 进入正确账号的内容管理和上传页，查找同一作品。已有草稿从「继续编辑」打开。作品已发布、审核中或已定时的情况下沿用已有记录。
2. 上传用户选定的成片，填写标题、简介和来源。作品描述中的话题按每条内容选择，优先使用平台候选并核对最终显示。选择方法见[话题与提交核对](references/queue.md#话题与提交核对)。需要横竖封面时分别检查 4:3 和 3:4 的裁剪预览。竖图居中裁切可能切掉标题，可以单独准备横图。
3. 按项目设置核对可见范围、保存权限和内容声明。合成配音的标识以当时平台入口和适用要求为准。保存草稿前先确认预览对应当前成片。
4. 只做预览时停在编辑页。保存草稿时用「暂存离开」。返回上传页后从「继续编辑」重新打开，核对标题、简介、封面及已设置的声明，再把实际结果写入平台状态记录。
5. 草稿重新打开后，保存权限等选项可能恢复默认值。提交前按页面现值再核对，项目设置为公开且禁止保存时，逐条确认「公开」和「保存权限 → 不允许」。使用 `sau` 时先读当前命令契约。其 `douyin upload-video` 用于投稿提交，草稿使用创作者中心的暂存入口。
6. 用户授权正式发布时，按要求选择立即发布或定时档位。提交一次后，到内容管理核对作品与状态。分别记录已定时、审核中和已发布。状态不明时先核查再重试。

## 本地排期

临时选题与常规片共用一张排期表。优先片占下一可调整档，常规片保留相对顺序并顺延。按目标平台和账号核对占用的档期。具体编号、例子和记录字段见[排期与去重](references/queue.md)。

需要制作或核验带高亮词汇、配音和片尾练习的成片时，参考[短视频制作与核验](references/video-production.md)。
