# 接入事实表与判定口径

只在需要接入、调通或评审新供应商时读取本文件。

## 最小输入

| 分类 | 必需信息 | 缺失时处理 |
| --- | --- | --- |
| 身份 | 用户指定供应商/源名称、目标环境 | 使用“未知”，不要从域名擅自命名 |
| 网络 | Base URL、完整路径、区域、超时 | 只做静态 URL 检查 |
| 鉴权 | Header 名、scheme、API 版本、附加签名 | 不发送请求 |
| 协议 | OpenAI、Anthropic、方舟/Action 或自定义 schema | 列出差异和待适配项 |
| 模型 | 实际模型 ID、别名、能力、流式语义 | 不把上游模型名当作供应商模型 ID |
| 计费 | 哪些接口计费、最小规格、预算/调用上限 | 不执行真实调用 |
| 结果 | usage、错误结构、request/trace ID、异步状态 | 报告标为证据缺口 |
| 安全 | Key 来源、目标文件是否 Git 跟踪、日志保留 | 不持久化真实凭据到跟踪文件 |

## 三种操作的边界

### 通常可视为准备工作

- 阅读本地文件和官方文档；
- 静态校验 URL、Header、JSON、Postman schema；
- 生成 curl、PowerShell、Bash、Postman JSON；
- 对已有响应、日志和历史结果做离线分析。

这些动作不访问供应商。生成物可以包含可能计费的请求，但要用名称和说明标出风险。

### 仅在有免费证据时执行

- 用户授权目标上的 DNS、TCP、TLS 检查；会产生网络访问，但不发送推理请求；
- 官方明确的 `/health`、`/models`、只读列表或查询接口；
- 查询用户已提供的既有 task/resource；
- 明确不会创建资源、不会触发推理且不计费的鉴权探测。

“通常不收费”不是证据。文档不明确时，退回准备模式。

### 需要当前任务明确授权

- Chat/Responses/Messages 推理；
- 图片、视频、语音生成或任务创建；
- 上传、素材导入、认证会话创建；
- 删除、取消、更新资源；
- 批量、并发、性能或缓存测试。

## 协议核对

至少核对：

- URL 是否已经包含 `/v1`，避免重复拼接；
- `Authorization: Bearer`、`x-api-key`、`X-Api-Key` 等是否精确；
- API 版本 Header、Content-Type、模型字段和 max tokens 字段；
- 流式事件格式、结束标记、usage 出现位置；
- 异步创建、查询、取消路径和状态枚举；
- 错误状态码是否被网关重写；
- request/trace ID、usage 和计费单位能否留证。

## 统一状态

- **GO**：接入所需字段齐全，协议和风险已核对；不代表性能或业务验收通过。
- **NO-GO**：存在已证实的协议/鉴权/计费/安全阻断项。
- **待补资料**：证据不足，不能判断；不要降格写成 NO-GO。
- **免费连通已验证**：仅代表被执行的只读接口；不代表模型推理可用。
- **真实推理已验证**：必须有实际请求、响应和用量证据，并说明是否计费。

## 交付最小内容

1. 对象、环境与资料来源；
2. 协议/鉴权/模型事实表；
3. 已执行动作与未执行动作；
4. 免费连通性证据；
5. 可能计费/写入请求清单；
6. GO/NO-GO/待补资料；
7. 可直接执行的命令或 Collection 位置；
8. 凭据与敏感信息处理说明。
